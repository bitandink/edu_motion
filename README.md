# Education Motion Detail Concept

교육 관련 모션 상세페이지 프로토타입입니다.

## Stack

- Next.js App Router
- TypeScript
- CSS Modules
- React hooks
- requestAnimationFrame 기반 scroll progress
- 외부 모션 라이브러리 없음

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 여세요.

## 구현된 섹션

1. Hero + 카카오톡 알림
2. Problem / 10 Minutes
3. Sticky phone learning experience
4. 10 minute message
5. Learning system
6. Calendar routine
7. DAY 1 → 365 scroll counter
8. Benefits
9. CTA
